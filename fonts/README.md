# ملفات الخطوط

حط ملفات خطوط وزارة الثقافة هنا بهالأسماء بالضبط (woff2 أفضل، و ttf تشتغل كاحتياط):

| الملف                  | الخط           | الاستخدام                      |
|------------------------|----------------|--------------------------------|
| `Masmak-Regular.woff2` | حرف المصمك 400 | النصوص والفقرات                 |
| `Masmak-Medium.woff2`  | حرف المصمك 500 | (اختياري) النصوص المتوسطة       |
| `Masmak-Bold.woff2`    | حرف المصمك 700 | العناوين والأزرار               |
| `Saudi.woff2`          | الخط السعودي   | الشعار، الشارات، الأرقام المميزة |

لو عندك TTF/OTF بس، حوّلها لـ woff2:

```
pip install fonttools brotli
python tools/convert-fonts.py "مسار/الملف.ttf" fonts/Masmak-Bold.woff2
```

لو ما حطيت الملفات، الموقع يستخدم IBM Plex Sans Arabic من Google Fonts تلقائياً.
