# ملفات الخطوط

| الملف                 | الخط                     | الاستخدام                                  |
|-----------------------|--------------------------|--------------------------------------------|
| `Masmak-Bold.woff2`   | حرف المصمك (Bold 700)    | العناوين، الأزرار، القائمة، الأسئلة         |
| `Saudi-Regular.woff2` | الخط السعودي 400         | الشارات، الجملة التعريفية في التذييل       |
| `Saudi-Bold.woff2`    | الخط السعودي 700         | الشعار، "خلّه علينا"، الأرقام المميزة       |

حرف المصمك متوفر بوزن واحد بس، عشان كذا الفقرات تستخدم IBM Plex Sans Arabic (من Google Fonts).
لو حصلت أوزان ثانية للمصمك (Regular / Medium)، حوّلها لـ woff2 وأضف لها `@font-face` في `css/style.css`:

```
pip install fonttools brotli
python tools/convert-fonts.py "مسار/الملف.otf" fonts/Masmak-Regular.woff2
```

ملفات التحميل الأصلية محفوظة في `fonts/_source/` (مستثناة من git).
